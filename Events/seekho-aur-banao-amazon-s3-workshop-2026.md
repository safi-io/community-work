## Contributions

- Conducted the third-day session of the SEEKHO AUR BANAO workshop series as Tech Lead at AWS Student Builder Group — CUI Sahiwal.
- Introduced participants to Amazon S3 and the fundamentals of cloud object storage.
- Explained how Amazon S3 can be used to store and manage files in the cloud.
- Demonstrated how cloud storage can support application deployment and hosting.
- Delivered practical guidance to students beginning their cloud computing journey.

## Session Highlights

The session focused on:

- Introduction to Amazon S3.
- Fundamentals of cloud object storage.
- Understanding cloud storage use cases.
- Using Amazon S3 for application deployment and hosting.
