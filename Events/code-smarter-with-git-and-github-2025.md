# Code Smarter with Git & GitHub

> A hands-on Git and GitHub workshop focused on practical version control, collaboration workflows, and helping students get started with open-source development.

| Field | Details |
|---|---|
| **Date** | 13 October 2025 |
| **Category** | Technical Workshop |
| **Organization** | Self-hosted |
| **My Role** | Workshop Instructor / Host |
| **Location** | C-Lab 4, C Block, COMSATS Sahiwal |
| **Audience** | Nearly 90 students and professors |
| **Duration** | 01:40 PM – 03:05 PM |
| **Sponsorship** | GitHub Education |
| **Format** | Self-hosted, on-campus |

## Contributions

- Hosted and delivered a hands-on workshop introducing Git and GitHub.
- Covered essential Git commands and workflows, including `git init`, `add`, `commit`, `push`, and `pull`.
- Shared practical version control techniques and collaboration best practices.
- Helped participants understand how Git and GitHub fit into real-world software development workflows.
- Engaged with nearly 90 attendees, including students and faculty members.
- Contributed to creating an environment for learning, collaboration, and open-source participation.

## Event Highlights

- Most participants rated their confidence in using Git and GitHub at 4–5 out of 5.
- Approximately 60% of attendees were already using the GitHub Student Developer Pack.
- GitHub-sponsored merchandise was distributed to participants.
- Prizes were awarded to active participants.
